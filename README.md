# 3D Narrative Informatics & Blossom Topology Analytics

An interactive web-based data visualization suite designed to map, segment, and compare high-frequency natural language processing (NLP) metrics across classical literature using 3D WebGL geometries. 

By running text-parsing pipelines over unstructured book sequences, chapter-level sentiment vectors, volume, and lexical profiles are dynamically translated into unique physical dimensions—forming interactive digital "blossoms."

## Geometric Feature Mappings
The data topology engine maps programmatic literary dimensions directly to WebGL geometric constants:

* **Petal Length: Word Count:** Longer petals capture expansive text volume and extended structural prose segments.
* **Petal Width: Lexical Diversity:** Flare thresholds represent a highly varied, unique vocabulary profile within the chapter.
* **Petal Tip Curl: Sentiment Polarity:** Upward curling geometries reveal narrative optimism, while downward folding signals somber text boundaries.
* **Edge Ripple: Punctuation Velocity:** High-frequency edge waves reveal heavy reliance on structural punctuation markers (commas, semi-colons, dialogue breaks).
